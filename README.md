# 编剧助手 · 开发文档

> 一款面向 15 秒短片创作的纯文字分镜规划工具。支持 iOS 14 与 Windows 双端，项目托管在 GitHub，通过 GitHub Actions 自动打包。iOS 采用未签名产物，仅用于验证构建链路。

---

## 一、产品概述

- 产品名称：编剧助手
- 目标用户：需要快速规划 15 秒短视频分镜的创作者
- 核心形态：纯文字分镜规划工具（不含视频渲染，只产出结构化分镜脚本）
- 支持平台：iOS 14+ / Windows
- 技术栈：Flutter + Dart
- 分发方式：GitHub 托管，GitHub Actions 自动打包；iOS 出未签名包
- 产品目标：让创作者围绕创作效率、时间控制与数据安全，完成从角色设定、分镜编排、时长校验到脚本导出的一整套分镜规划工作。

---

## 二、核心流程

1. 新建项目，设置标题、总时长、分镜数量。
2. 在角色库中建档角色（姓名、性别、年龄、外貌、服装、性格、语速），供全项目引用。
3. 默认生成 4 个分镜，可随时新增、删除、复制、排序、禁用。
4. 编辑分镜：画面、镜头、光线、台词、声音、动作流程等，台词角色直接从角色库选取。
5. 系统自动计算时间标记、剩余时长、台词预估时长（按所选角色的语速）。
6. 实时校验总时长、分镜时长、台词时长、字段完整性、跨分镜一致性。
7. 自动保存项目，支持撤销/重做和草稿恢复。
8. 可套用模板，也可保存当前分镜为模板。
9. 导出前进入统一校验中心，修复问题后导出 Markdown/TXT/JSON。

## 四、角色库

角色是项目级一等公民：一次建档、全局引用、改一处同步所有分镜，并作为一致性检查与台词语速估算的基准。

### 4.1 角色字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 姓名 | 文本 | 角色名，下拉与台词角色显示用 |
| 性别 | 下拉 | 男 / 女 / 其他 / 未设定 |
| 年龄 | 文本 | 年龄段或具体年龄，供创作参考 |
| 外貌 | 文本 | 身高、体型、发型、显著特征（如伤疤位置） |
| 默认服装 | 文本 | 一致性检查服装字段的基准值 |
| 性格 | 文本 | 台词语气与情绪参考 |
| 语速 | 下拉/输入 | 该角色台词语速（字/分钟），默认 200，用于台词时长估算 |
| 备注 | 文本 | 自由补充 |

### 4.2 角色操作

- 新增、编辑、删除角色。
- 角色卡片折叠展开，展开即编辑。
- 查看"被引用分镜"，点击定位。
- 复制角色（生成副本）。
- 角色库变更实时同步到所有引用该角色的分镜。

### 4.3 分镜与角色的引用关系

- 分镜的"台词角色"从下拉选取，选中即写入 characterId（引用角色库）；仍保留自定义文本兜底。
- 角色改名：所有引用该 characterId 的分镜台词角色显示同步更新。
- 角色删除且仍有引用时，弹二次确认，处理方式：
  - 保留原台词文本（把引用降级为自定义文本，不丢内容）；
  - 改为其他角色；
  - 取消删除。
- 未被任何分镜引用的角色可直接删除。

### 4.4 角色库作为一致性基准

- 服装冲突：分镜"保持特征 / 背景变化"里的服装描述若与角色库"默认服装"矛盾，产生冲突提示。
- 外貌/伤疤：分镜中提及的外貌特征与角色库"外貌"不一致时提示（如伤疤左右、发型变化）。
- 称呼一致：同一 characterId 在不同分镜的台词角色显示统一（避免"男主/他/阿明"混用）。

### 4.5 角色语速与台词估算联动

- 台词时长估算优先使用所选角色的"语速"字段；未选角色或角色未设语速时回落到项目默认语速（200 字/分钟）。
- 例：某角色语速设为 240，同样 12 字台词估算 3.0s；默认语速下估算 3.6s。

### 4.6 角色库范围

- 角色库存于项目 JSON（项目级）。
- 可另存"全局角色库"，新建项目时选择导入，便于系列短片复用同一批角色。

## 五、分镜管理

分镜为动态列表，数量随创作需要自由调整。

### 5.1 分镜操作

- 新增分镜、删除分镜、复制分镜（复制全部字段作为新分镜插入）。
- 拖拽排序、上移/下移。
- 启用/禁用。
- 分镜编号自动重排、时间标记自动重排。

### 5.2 分镜状态

| 状态 | 说明 |
|---|---|
| 启用 | 参与时长计算、导出、一致性检查 |
| 禁用 | 保留内容，但不参与总时长和导出（卡片变灰） |
| 空分镜 | 未填写任何字段，导出时自动忽略 |
| 复制分镜 | 复制全部字段，作为新分镜插入 |

## 六、时长联动规则

### 6.1 基本约束

- 总时长默认 15 秒；分镜数量默认 4 个。
- 每个分镜最小 1 秒，最大不超过总时长。
- 所有启用分镜时长之和必须等于总时长。

### 6.2 调整方式

| 操作 | 行为 |
|---|---|
| 修改总时长 | 提示"平均分配"或"按比例重算" |
| 修改某个分镜时长 | 自动调整最后一个启用分镜补齐 |
| 锁定分镜时长 | 该分镜不参与自动分配 |
| 删除分镜 | 剩余时长重新分配 |
| 新增分镜 | 从最后一个分镜或剩余时长中扣除 |
| 禁用分镜 | 该分镜时长从总时长中移除 |

### 6.3 时长条实时提示

```text
已用 13.5s / 15s   剩余 1.5s   台词预估 4.2s
```

剩余为负标红，台词预估超出分镜时长标黄，总时长不匹配时导出置灰。

---

## 七、台词时长与语速校验

### 7.1 语速规则

- 默认中文语速 200 字/分钟，约 3.3 字/秒。
- 可切换慢速、正常、快速；不同角色的语速优先取角色库中该角色的"语速"字段（见 4.5）。
- 中文按字符估算，英文按单词估算。

### 7.2 台词字段旁显示

```text
台词：你真的要走吗？
角色语速：男主 200 字/分   字数：7   预估 2.1s   分镜时长 4s   正常
```

### 7.3 状态规则

| 情况 | 提示 |
|---|---|
| 台词时长 <= 分镜时长 | 绿色：时间充足 |
| 台词时长接近分镜时长 | 黄色：时间偏紧 |
| 台词时长 > 分镜时长 | 红色：超出 X.Xs |
| 有台词角色但无台词 | 校验提示 |
| 台词为空 | 不计算预估时长 |

## 八、自动保存、草稿与撤销/重做

### 8.1 自动保存

- 编辑后 700ms 防抖自动保存；保存失败提示"保存失败，请重试"。
- 页面显示：正在保存 / 已保存 / 保存失败。
- 角色库编辑同样纳入自动保存与撤销/重做范围。

### 8.2 草稿恢复

- 异常退出后重新进入项目时提示恢复草稿。
- JSON 损坏时保留原文件并生成 .corrupt 备份。

### 8.3 撤销/重做

- 支持撤销/重做分镜增删、字段修改、排序、时长调整、角色增删改。
- 快捷键：Windows Ctrl+Z / Ctrl+Shift+Z；macOS Cmd+Z / Cmd+Shift+Z。
- 撤销历史在进程内维护，不无限增长。

### 8.4 未保存离开提示

- iOS 返回、Windows 关闭窗口时，若有未保存变更，弹出二次确认。

## 九、模板系统

### 9.1 内置模板

对话、追逐、情绪特写、空镜转场、开场悬念、结尾反转。

### 9.2 模板操作

| 操作 | 说明 |
|---|---|
| 套用模板 | 应用到当前分镜或全部空分镜 |
| 保存模板 | 将当前分镜保存为自定义模板 |
| 预览模板 | 查看模板包含哪些字段 |
| 覆盖规则 | 覆盖全部 / 只填空字段（默认只填空字段，避免清空已填内容） |
| 管理模板 | 重命名、删除、排序 |
| 模板范围 | 项目级 / 全局级 |

### 9.3 模板与角色的关系

- 模板中的台词角色以"占位角色"存储；套用模板时，占位角色不覆盖项目角色库，只在当前分镜留空或由用户选角，避免污染项目角色数据。

### 9.4 模板数据结构

```dart
class Template {
  String id;
  String name;
  String scope; // project / global
  ShotBlock snapshot;
  DateTime createdAt;
  DateTime updatedAt;
}
```

## 十、一致性检查

### 10.1 检查维度

| 维度 | 检查内容 | 基准来源 |
|---|---|---|
| 角色 | 同一角色称呼是否一致 | 角色库 |
| 服装 | 服装描述是否冲突 | 角色库"默认服装" |
| 道具 | 道具出现/消失是否合理 | 分镜内容 |
| 伤疤/特征 | 外貌/特征是否前后矛盾 | 角色库"外貌" |
| 光线 | 同一场景光线是否突变 | 分镜内容 |
| 时间 | 白天/夜晚是否冲突 | 分镜内容 |
| 环境音 | 场景变化后环境音是否仍合理 | 分镜内容 |
| 背景音乐 | 情绪是否与画面冲突 | 分镜内容 |

### 10.2 冲突展示

- 一致性面板列出所有冲突，每条显示涉及的分镜编号。
- 点击冲突定位到对应分镜；支持忽略、标记已确认、快速修复。

```text
冲突：服装不一致
角色：男主   角色库默认服装：深色风衣
分镜 3：白色衬衫
建议：确认是否为换装场景。
[定位分镜 3] [打开角色库] [忽略]
```

## 十一、自定义选项管理

- 可自定义：台词角色（自定义兜底）、环境音、背景音乐、镜头运动、光线氛围、节奏标签。
- 管理功能：新增、重命名、删除、排序；支持项目级与全局默认级；导出时保留自定义选项。
- 台词角色的"结构化设定"归角色库管理，自定义选项只保留"无档案的临时角色名"作为兜底。

```dart
class CustomOptions {

  List<String> ambientSounds;
  List<String> bgms;
  List<String> cameraMoves;
  List<String> lightingMoods;
  List<String> paces;

```

## 十三、统一校验中心

导出前必须通过校验，分级：错误禁止导出，警告允许导出但提示风险，提示不影响导出。

| 校验项 | 级别 |
|---|---|
| 所有启用分镜是否全空 | 错误 |
| 分镜时长是否小于 1 秒 | 错误 |
| 总时长是否匹配 | 错误 |
| 台词角色引用了已删除/失效的角色 | 错误 |
| 有台词角色但无台词 | 警告 |
| 环境音选"无"却有补充说明 | 警告 |
| 背景音乐选"无"却有补充说明 | 警告 |
| 镜头运动为空但有镜头补充 | 警告 |
| 台词时长超出分镜时长 | 警告 |
| 角色库中存在从未被引用的角色 | 提示 |
| 一致性冲突未处理 | 提示 |

## 十四、分镜字段与快捷选择选项库

### 14.1 字段类型划分

| 类型 | 字段 | 交互方式 |
|---|---|---|
| 自动 | 分镜编号、时间标记 | 系统生成 |
| 输入 | 时长 | 滑块 + 数字输入 + 锁定 |
| 快捷选择 | 节奏、镜头运动、光线氛围、台词角色 | 下拉菜单 |
| 快捷选择 + 补充 | 环境音、背景音乐 | 下拉菜单 + 文本补充 |
| 自由填写 | 主体动作、动作开始/发展/结束、镜头补充说明、背景变化、保持特征、台词内容 | 文本框 |

- 台词角色下拉：选项来源 = 角色库角色 + 自定义兜底（见第十一章）。

### 14.2 下拉选项库（默认值，均可在项目/全局级自定义增删）

- 节奏：慢 / 正常 / 快 / 急促
- 镜头运动：固定 / 推近 / 拉远 / 上摇 / 下摇 / 左摇 / 右摇 / 横移 / 跟拍 / 俯拍 / 仰拍 / 环绕
- 光线氛围：自然光 / 暖黄光 / 冷蓝光 / 逆光 / 侧光 / 顶光 / 低照度 / 高对比 / 柔光 / 硬光 / 霓虹光 / 烛光
- 台词角色：读取角色库（如男主、女主），并支持自定义兜底（男主 / 女主 / 男配 / 女配 / 旁白 / 群演 可作为初始角色）
- 环境音：无 / 雨声 / 风声 / 雷声 / 海浪 / 鸟鸣 / 车流 / 脚步声 / 钟表滴答 / 城市喧嚣 / 室内安静 / 键盘敲击 / 电话铃声 / 自定义
- 背景音乐：无 / 紧张 / 悲伤 / 温馨 / 激昂 / 悬疑 / 轻快 / 浪漫 / 压抑 / 史诗 / 自定义

> 最快填一个分镜的路径：选节奏 -> 选镜头 -> 选光线 -> 选角色 -> 填台词 -> 选环境音 -> 选背景音乐。

## 十五、时间规则

- 默认总时长：15 秒；默认分镜数：4 个；每个分镜至少 1 秒。
- 时间标记自动计算，分镜增删/排序/改时长后自动重排。
- 所有启用分镜时长之和必须等于总时长，否则导出前禁止导出。

## 十七、导出规则

### 17.1 分镜层级

- 只要该分镜有任何一个字段被填写且处于启用状态，就输出这个分镜。
- 禁用或全部为空的分镜不输出；所有可输出分镜都为空时提示"暂无可导出内容"。

### 17.2 字段层级

- 文本字段：去除首尾空格后不为空才输出。
- 时长字段：大于 0 才输出。
- 下拉字段（节奏、镜头运动、光线氛围、台词角色、环境音、背景音乐）：选择了有效选项才输出。
- 台词：只有填了台词内容才输出；若同时选了台词角色则一并输出（输出角色名）。
- 环境音/背景音乐：选了"无"或空值不输出；选了有效选项则输出选项名，有补充说明则拼在后面。
- 空字段不输出 null、不输出"未填写"、不输出空行。

### 17.3 角色导出规则

- Markdown/TXT：导出时可在开头附加"角色表"段落，列出角色姓名、外貌、默认服装等，便于阅读脚本。
- JSON：完整保留 characters 及分镜的 dialogueCharacterId，保证导入后引用关系不丢。

### 17.4 动作流程拼接

- 只把"开始 / 发展 / 结束"中已填写的部分拼接，格式：开始—XXX -> 发展—XXX -> 结束—XXX。

### 17.5 导出示例

```markdown
# 角色表

- 男主：短发·瘦高，深色风衣，左脸有旧伤疤，语速 200
- 女主：长发，红色围巾，语速 180

# 分镜 1

- 时长：4 秒
- 节奏：正常
- 时间标记：00:00 - 00:04
- 主体动作：男主站在窗前
- 动作流程：开始—抬头看窗外 -> 发展—手扶窗框 -> 结束—转身离开
- 镜头运动：推近
- 背景变化：窗外雨势加大
- 光线氛围：冷蓝光
- 环境音：雨声
- 背景音乐：悲伤
- 保持特征：风衣、伤疤位置不变

# 分镜 2

- 时长：4 秒
- 节奏：正常
- 时间标记：00:04 - 00:08
- 主体动作：男主回头看向女主
- 镜头运动：推近
- 光线氛围：暖黄光
- 台词角色：女主
- 台词：你真的要走吗？
- 环境音：室内安静
- 保持特征：女主红色围巾不变
```

### 17.6 导出增强

- 导出前进入统一校验中心，错误项禁止导出。
- 导出文件命名规则：{项目标题}_{格式}_{日期}.{后缀}。
- 支持复制、保存到指定目录、系统分享面板；Markdown/TXT/JSON 切换后实时预览。

## 二十一、开发阶段规划

### 阶段 1：分镜管理
新增、删除、复制、排序、禁用；分镜编号与时间标记自动重排；拖拽排序。

### 阶段 2：时长联动
总时长、分镜时长、剩余时长联动；锁定分镜；平均分配与按比例重算。

### 阶段 3：角色库
Character 模型与角色库页；台词角色下拉读取角色库；角色改名同步引用；删除角色保护；角色语速接入台词估算。

### 阶段 4：台词校验
字数统计、语速估算、台词时长与分镜时长比对、台词字段旁预估显示。

### 阶段 5：自动保存与撤销/重做
700ms 防抖自动保存、草稿恢复、撤销/重做栈、未保存离开提示。

### 阶段 6：模板系统
内置模板、套用模板、保存自定义模板、覆盖规则、模板管理界面、模板占位角色处理。

### 阶段 7：一致性检查
以角色库为服装/外貌/称呼基准；跨分镜字段汇总、冲突检测规则、一致性面板、定位/忽略/确认。

### 阶段 8：自定义选项
环境音/背景音乐/镜头/光线/节奏自定义；临时角色名兜底；项目级与全局级；增删改排序。

### 阶段 9：项目生命周期
重命名、删除、复制（含角色库）；搜索/排序/筛选；JSON 导入导出闭环（含角色库）；项目备份。

### 阶段 10：统一校验中心
导出前校验；角色引用失效检查；错误/警告/提示分级；一键定位问题分镜。

### 阶段 11：CI 与测试
打包未签名 iOS + Windows；补充单元测试（含角色引用同步、schema 迁移）、Widget 测试、导出快照测试，CI 跑 flutter test。

## 二十二、验收要点 Checklist
